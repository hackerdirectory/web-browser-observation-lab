# Browser Observation Lab

Document, DOM/CSS ve event-loop sonuçlarını 18 alanda tahmin et; native Browser gözlemini kaydet ve nedenini açıkla.

Yerel, sentetik veriyle foundational manual pratik. 1 workbook: WEB-LAB-04. Her workbook kısa bir bağımsız görev ve evidence ölçütüyle biter.

## Başlat

Repository’yi ZIP olarak indirip çıkar veya clone et. Repository klasöründe terminal aç. Node.js 20+ yeterli; paket kurulumu gerekmez.

```sh
cd lab
node server.mjs
```

Adresi aç: `http://127.0.0.1:4194/`.

`lab/index.html` dosyasını doğrudan browser’da da açabilirsin.

## Labı tamamla

1. [Türkçe workbook](lab/README.md) ile başla; gözlemden önce tahmin et.
2. Gerektiğinde [ipuçlarını](lab/HINTS.md) aç; gözlemden sonra [çözümü](lab/SOLUTION.md) oku.
3. Son görevi tamamla; tahmin, gözlem ve açıklamanı yerelde tut.

İlgili dersler: WEB-10.01, WEB-10.02, WEB-10.03. [English workbook](lab/README.en.md)

Bu öğrenme pratiği site sınavlarından ve sertifikalarından ayrıdır. Kişisel evidence’i `.local-results/` altında tut; Git commit’ine ekleme. Model sınırları ve sıfırlama adımları workbook’te açıklanır.
